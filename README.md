# 3D Product Demo

Standalone demo of 3D product viewing, AR "view in your room" and sunglasses try-on, using sample products.
Built with Google model-viewer, three.js and MediaPipe Face Landmarker.

Models from the Khronos glTF Sample Assets (CC BY 4.0 / CC0 1.0); see the page footer and `models/*.LICENSE.md`.
